# tve-timeline
https://konataxdd.github.io/tve-timeline/

Timeline for TVE (True Vanilla Experiment), a (currently offline) Minecraft anarchy server with almost no restrictions. Uses the [wiki's timeline](https://true-vanilla.fandom.com/wiki/TVE_timeline) (with additions from [GlinglinMerguez's v5 timeline](https://www.tiki-toki.com/timeline/entry/1748870/TVE-Official-Timeline-V5/)) as a source.

This is the 6th such visual timeline in the history of TVE.

Current maintainers:

- EficaciousMig47 (extended the wiki timeline to 2026)
- exxxx (vis.js implementation)
